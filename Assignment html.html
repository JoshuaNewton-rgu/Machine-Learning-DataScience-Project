Student Academic Stress Real World Dataset From Kaggle¶

Downloaded on 28/11/2025¶

Dataset overview¶

The dataset that i picked looks at academic stress level and how they cope with said stress levels and other factors which could effect the stress level.

Objectives¶

This dataset will be able to look at factors which effect stress in students and compare it against their coping mechanisms. Factors which effect stress are peer pressure, academic pressure from home, academic competition and the study environment.

Data Cleaning¶

Removed data where users preferred not to say about their smoking / drinking habits and changed values from yes / No / Prefer not to say to 1 and 0 for yes and no.

Research paper which relates to this machine learning model¶

Real Time Identification of Students' Stress Factors using Machine Learning Techniques¶

Literature Review / Research Background¶

Student Academic Stress Real World Dataset From Kaggle¶

Verma et al aimed to develop a machine learning system which could be used to identify student stress based on categorical factors. Their approach used a decision tree classifier. They used a different dataset butt they both have similar categories which makes this paper relevant.

Verma et al achieved an accuracy of 80% – 90% which sets a strong benchmark to aim for. Due to my dataset being smaller it only achieved a accuracy of 75% this is appropriate as getting above 80% accuracy on a dataset this small can be difficult without overfitting.

This is a good source for this project for a few reasons: It aims to find the same outcome as my project which is to calculate the stress based on external factors. It is also a recent publication as it was published in 2024 which shows that they are using current best practices It also works well due to it being relevant to my experiment as there are currently no papers published which use the dataset used in this project

Refrences¶

** S. Verma, R. Kumar, P. Pani, A. Mohanty, and P. Chaudhury, "Real Time Identification of Students' Stress Factors using Machine Learning Techniques," in 2024 International Conference on Intelligent Computing and Sustainable Innovations in Technology (IC-SIT), Bhubaneswar, India, 2024, pp.**

def encode_variables():
    X_train_e = pd.get_dummies(X_train, columns=[
        'Academic Stage',
        'Peer Pressure',
        'Home Pressure',
        'Study Env', 
        'Coping Strategy', 
        'Bad Habits',
        'Academic Comp',
                ])

    X_test_e = pd.get_dummies(X_test, columns=[
        'Academic Stage',
        'Peer Pressure',
        'Home Pressure',
        'Study Env', 
        'Coping Strategy', 
        'Bad Habits',
        'Academic Comp',
            ])
    
    X_test_e = X_test_e.reindex(columns=X_train_e.columns, fill_value=0)

    y_train.replace('no', 0, inplace=True)
    y_train.replace('yes', 1, inplace=True)
    y_test.replace('no', 0, inplace=True)
    y_test.replace('yes', 1, inplace=True)

    return X_train_e, X_test_e

Conclusion¶

Best model : Random Forest Classifier¶

The verma et al study achieved 80% - 90% accuracy at predicting student stress using a decision tree, My best model achieved 75% accuracy which is lower but still within reason due to the following factors:

The dataset i used was significantly smaller with only 139 samples, Smaller datasets limit model capability and make high accuracy more challenging to achieve The Stress_3class variable shows a class imbalance (60% High, 29% Medium and 11% Low stress) This makes a balanced prediction across all 3 classes much more difficult
